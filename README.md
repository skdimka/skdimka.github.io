# Dmitrii Skopintsev — portfolio

Personal site built with Astro, React and GSAP. English at `/`, Russian at
`/ru/`.

```sh
npm install
npm run dev        # localhost:4321
npm test           # unit + Storybook (a11y) tests
npm run storybook  # component workbench at localhost:6006
```

Architecture and conventions: [AGENTS.md](./AGENTS.md).
